About Releases

  • GA (General Availability) — The stable, production-ready release (e.g., rhoai/3.5). All quality gates must pass.
  • EA1 / EA2 (Early Access) — Pre-release milestones (e.g., rhoai/3.6-ea.1). These validate features before GA. EA1 = first milestone, EA2 = second milestone (closer to GA).
  • EA and GA results are combined per version to show the full release lifecycle: EA1 → EA2 → GA.
